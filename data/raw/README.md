# Raw input data

Place the required input files here before running the workflow:

- `CHEMBL5319.xlsx` — ChEMBL-derived DDR1 activity records with SMILES, activity type, and pChEMBL values.
- `FDA_DrugBank_cleaned.xlsx` — cleaned DrugBank compound table containing compound names and SMILES.
- `5SB1.pdb` — the DDR1 crystal structure used for redocking.

These source files are not bundled with this repository. Confirm data-use terms and retain source/version/date information. The notebooks expect these exact filenames unless their configuration cells are changed.
